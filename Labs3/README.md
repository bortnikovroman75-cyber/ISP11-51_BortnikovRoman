# Лабораторная работа №15: Анализатор текста
**Студент:** Бортников Роман, группа ИСП 11-51

## Постановка задачи
Разработать консольное приложение, которое читает текстовый файл, подсчитывает частоту встречаемости каждого слова (игнорируя короткие слова и знаки препинания), выводит Топ-5 самых частых слов и сохраняет результат в отдельный файл.

## Инструкция по запуску
1. Убедитесь, что установлен Python 3.8+.
2. Перейдите в папку `Лаб15-АнализаторТекста`.
3. Запустите: `python src/main.py`.
4. Следуйте меню.

## Формат файла с данными
- Входной файл: `data/input_text.txt` (UTF-8).
- Выходной файл: `data/result.txt` (результаты анализа).

## Описание коллекций
Используется **словарь (dict)** для хранения пар «слово — количество вхождений». Это оптимальный выбор, так как поиск и обновление значения в словаре выполняются за O(1).
